# Inspiración de diseño y flujos

Patrones tomados (no copiados) de portales y sitios de lujo, y cómo se tradujeron en Home Finder Exclusive:

| Patrón observado | De dónde | En Home Finder Exclusive |
|---|---|---|
| Búsqueda dividida: lista + mapa sincronizados, pines con precio | Zillow / Redfin | `#buscar`: hover en tarjeta resalta el pin y viceversa; "Buscar mientras muevo el mapa" |
| Filtros como píldoras con menú, chips de filtros activos | Zillow | Barra de filtros fija con resumen en cada píldora y chips para quitar |
| Corazón para guardar y lista de guardadas | Zillow, Airbnb | Guardadas persistentes + contador en el encabezado |
| Ficha con mosaico de fotos y "Ver todas las fotos" | Zillow | Mosaico 1 + 4 y galería a pantalla completa con teclado |
| Estimado de pago mensual en la ficha | Zillow | Calculadora con enganche, plazo y tasa |
| Precio por m² y comparación con el vecindario | Redfin | La función del A2: etiqueta + comparables visibles |
| Héroe a pantalla completa, navegación mínima, un color de marca distintivo, storytelling editorial | Sitios de lujo (The Agency, Sotheby's, Christie's) según análisis de Magier (2026) | Landing con foto a sangre, titular serif grande y azul marino como único color de marca |
| Galería tipo feed | Instagram | "Detrás de cada puerta": cuadrícula 3×3 que abre la ficha |
