# Home Finder

Sitio de listados inmobiliarios (Assignment 1) + **etiquetas automáticas de precio** (Assignment 2).

- `index.html` — la app.
- `price-tags.js` — lógica de la función: compara el precio/m² de cada propiedad contra el promedio de las otras de su zona y tipo de superficie.
- `test.js` — corre `node test.js` para ver la etiqueta calculada de cada propiedad.
- `PROMPT_LOG.md` — bitácora de prompts (especificación, decisiones, validación, uso de IA).
